# Task 1: Words Game (Игра в «Слова»)

Консольное приложение на C# (.NET)

## Реализованные требования
- **Функциональная парадигма:** неизменяемое состояние (`record`), чистые функции, LINQ и рекурсия без использования циклов.
- **Ограничение времени:** таймер на 15 секунд на каждый ход (`System.Timers.Timer`).
- **Валидация:** проверка длины исходного слова (8–30 символов), запрет на повторный ввод слов и базового слова, учет количества букв.
- **Локализация:** поддержка русского (`ru`) и английского (`eng`) языков интерфейса и алфавита.
